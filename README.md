CodSoft Java Development Internship

This repository contains my Java Development Internship tasks at CodSoft.

Task 1: Number Guessing Game

A Java program that generates a random number between 1 and 100. The user guesses the number and receives hints until the correct answer is found.

Task 2: Student Grade Calculator

A Java program that accepts marks for multiple subjects and calculates the total marks, average percentage, and grade.

Task 3: ATM Interface

A Java program that simulates basic ATM operations, including checking the balance, depositing money, and withdrawing money.
